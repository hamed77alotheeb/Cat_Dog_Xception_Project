# 🐱🐶 Cat vs Dog Image Classifier

## 📌 نبذة عن المشروع

هذا المشروع عبارة عن نظام لتصنيف الصور باستخدام تقنيات التعلم العميق، حيث يقوم بتحديد ما إذا كانت الصورة تحتوي على قطة (Cat) أو كلب (Dog).

تم بناء النموذج باستخدام بنية **Xception** المدربة مسبقًا على ImageNet، مع استخدام **Transfer Learning** و **Fine-Tuning** لتحسين أداء النموذج.

كما يحتوي المشروع على واجهة استخدام رسومية باستخدام **Gradio**، تسمح للمستخدم برفع صورة والحصول على الفئة المتوقعة ودرجة الثقة.

يهدف المشروع إلى:

2. استخدام نموذج Xception المدرب مسبقًا على ImageNet.

## 📌 الفرق بين Accuracy وConfidence

هناك فرق بين **دقة النموذج (Accuracy)** و**درجة الثقة (Confidence)**.

### Accuracy

هي مقياس يوضح نسبة التوقعات الصحيحة للنموذج عند اختباره على مجموعة كاملة من الصور.

مثال:

```text
Validation Accuracy = 99.73%
```

### Confidence

هي درجة ثقة النموذج في التنبؤ بصورة واحدة.

مثال:

```text
CAT
Confidence = 95.39%
```

لذلك من الطبيعي أن تكون دقة النموذج العامة مرتفعة، بينما تكون درجة الثقة في صورة معينة أقل من ذلك.
